# v0.1.1 Windows未署名試用版

2026-11-02時点で公開前の準備中。対象はWindows 11 x64です。ARM64向け、Store版、署名済みWindows版、macOSアプリは今回の配布に含めません。
v0.1.0のソース版に、Windows用セットアップEXEの試用配布を追加する方針です。閲覧機能と固定依存は変更しません。

## 導入前に確認すること

**インストーラーとmd-viewer本体にはWindowsのコード署名がありません。**
Smart App Control（SAC）・SmartScreen・組織のアプリ制御等で、ダウンロード・導入・起動をブロックされる場合があります。
**ブロックされた場合は導入を中止してください。** SACやDefenderの無効化、除外設定、信頼ルート追加、ブロックの回避操作は案内しません。
現在のHP実機で導入できることを保証する試用版ではありません。

Gitの署名コミット・署名タグ・署名付きチェックサムは、ソースと配布物を照合するためのものです。
EXEのWindowsコード署名や、Windowsによる実行許可・無警告・安全性の保証にはなりません。

利用者のStore登録、D-U-N-S、法人化、Rust・Node.js等の開発環境は不要です。
必要なのは、対応するWindowsとMicrosoft Edge WebView2 Runtimeです。WebView2がない場合、セットアップがMicrosoftから取得するためネット接続が必要です。
WebView2未導入のクリーン環境での一連の導入は未検証です。導入後のローカル文書閲覧はオフラインを想定しています。

## 配布物と入手先

公開時は[GitHub Releases](https://github.com/mt4110/md-viewer/releases)に、次をまとめます。準備中のファイルを公開済みとは扱いません。

| ファイル | 用途 |
| --- | --- |
| md-viewer_0.1.1_x64-setup.exe | Windows未署名NSISセットアップ。本体はx86_64向け |
| md-viewer-0.1.1-source.tar.gz | 同じコミットのソース。旧ラボの成果物を除いたもの |
| WINDOWS_TRIAL_v0.1.1.md | この案内。制約と確認手順 |
| LICENSE.txt / THIRD_PARTY_NOTICES.txt・json | 本体のMITと第三者の権利表示。セットアップにも同梱 |
| BUILD_INFO.json / SHA256SUMS | 対象コミット・ビルド条件・ハッシュの照合用 |

署名付きチェックサムを付ける場合は、署名と公開鍵も添付し、署名方式をReleaseに記載します。
GitHubが自動生成する「Source code」は旧ラボも含むリポジトリ全体です。上記の専用ソースアーカイブとは対象・ライセンス範囲が異なります。

必要なサイトは次の2つです。Storeの登録や署名購入は試用の条件ではありません。

| サイト | 用途 | 利用者が入力するもの |
| --- | --- | --- |
| [GitHub Releases](https://github.com/mt4110/md-viewer/releases) | EXE・ハッシュ・説明の取得 | 公開後のダウンロードにアカウント登録は不要 |
| [Microsoft WebView2](https://developer.microsoft.com/microsoft-edge/webview2/) | ランタイムの公式案内・入手 | 通常のランタイム入手にStore開発者登録は不要 |

## キーボードでの導入

1. Releaseの説明で対象バージョンと制約を読み、EXEとSHA256SUMSを同じフォルダーに保存します。
2. Windows PowerShellで、保存したEXEのハッシュを求めます。パスは実際の保存先に合わせます。

   ```powershell
   Get-FileHash -Algorithm SHA256 "$env:USERPROFILE\Downloads\md-viewer_0.1.1_x64-setup.exe"
   ```

3. SHA256SUMSの同じファイル名の値と一致するか確認します。不一致なら実行しません。
4. エクスプローラーでEXEを選んでEnterを押し、日本語セットアップを進めます。Tab／Shift+Tabで移動し、ボタンはEnter、チェック項目はSpaceで操作できます。
5. OSがブロック・警告した場合はそこで止めます。記録するのは表示文言と候補のハッシュです。保護設定は変更しません。
6. 導入できた場合はスタートメニューから起動し、Ctrl+Oで自分で用意した非機密のUTF-8 Markdownを開きます。

セットアップは現在のユーザーの領域への導入を設定しています。今回の候補で管理者権限の昇格が要求された場合は、承認せず状況を確認してください。
既定のMarkdownアプリの変更は任意であり、試用に必須ではありません。

## 所有者が確認するテスト

各行の結果は、実施した候補のハッシュとセットで記録します。未実施を合格扱いにしません。
OSが候補を拒否した場合、以下の起動後の項目は「ブロックのため未実施」で終了します。
過去の候補・Sandbox・UI回帰試験の結果を、今回の通常導入の成功には流用しません。

| 項目 | キーボードを中心とした確認 | 合格条件 |
| --- | --- | --- |
| 導入・起動 | 日本語セットアップ、スタートメニューから通常起動 | エラー・空画面がなく本文を開ける。OS保護・環境変数を変更しない |
| 日本語の文書 | Ctrl+Oで日本語・空白・#を含むファイル名を開く | 本文・表・コード・ローカル画像が読める |
| 目次・移動 | Tabで目次や文書リンクを選ぶ。Alt+←／→で往復 | 対象見出し・文書に移り、以前の位置へ戻れる |
| 検索・IME | Ctrl+F、日本語変換、Enter／Shift+Enter、Esc | 正しい一致箇所へ移動し、変換確定前に誤移動しない |
| タブ・再開 | 複数文書、Ctrl+Tab、読書位置変更、通常終了・再起動 | 選択したタブ・読書位置・設定が復元する |
| 表示・フォーカス | Ctrl+＋／－／0、Tab／Shift+Tab | 読める大きさへ変更でき、操作先が見える |
| 保存追従 | 専用の合成文書コピーを別エディタで通常保存・置換保存 | 本文が更新され、読書位置をできるだけ維持する。私的な原稿は使わない |
| 失敗からの復帰 | 空の文書・不正UTF-8を開く | 空文書を扱え、不正UTF-8では明確なエラーが出て既存文書へ戻れる |
| 外部アクセス | 外部画像とWebリンクを含む合成文書で、リンク確認をEscで閉じる | 外部画像を自動取得せず、キャンセルでブラウザが開かない |
| OS連携・読み上げ | 「プログラムから開く」、必要に応じNarrator | 実機で操作できた範囲を記録する。未実施なら未確認のまま残す |
| 更新 | 既存版の設定と文書を保全して更新を確認 | 版番号が0.1.1になり、設定と通常起動を確認できる |
| アンインストール | 個別に対象・データへの影響を確認してから行う | 所有者が選んだデータ保持・削除の動作に一致する |

アンインストールやデータ削除は、この案内の作成によって実行が承認されたものではありません。原本と既存の設定を保全し、対象を確認してから判断します。
Narrator・表示倍率ごとの操作、OS連携、更新・アンインストール等が未確認の場合、その事実を配布説明に残します。
