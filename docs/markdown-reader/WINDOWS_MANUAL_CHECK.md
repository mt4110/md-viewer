# Windows配布候補の実機確認

この手順は所有者による配布候補の受入確認用。インストーラーは未署名で、CI・実機導入・Gitタグの署名はそれぞれ別に確認する。
この手順や候補作成CIはGitHub Releaseやタグを作成しない。公開は対象コミット・権利表示・成果物を照合した後に判断する。
2026-10-31に所有者がHPのWindows本体で旧候補の導入・起動を確認した。下表は全項目が合格したという意味ではなく、再梱包後の候補でも導入と同梱物を確認する。

## 開始前

1. Windowsの画面を確認し、初回設定中なら必要な設定を本人が選び、デスクトップまで進める。
2. Windowsのエディション・バージョンと表示倍率を記録する。IPアドレスはUbuntuと同じとは限らない。
3. 必要ならMacからの接続方法を検討する。SSHやリモートデスクトップの有効化は、接続範囲・認証方法を決めてから扱う。
4. Package Windows test candidateの対象コミットと、Check md-viewerの成功を確認する。
5. 成果物のアップロードは既定で無効。第三者権利表示と共有範囲を確認してから保存方法を選ぶ。
   upload_artifactを明示的に有効にして保存した場合は、Actionsから取得・展開し、SHA-256をINSTALLER_SHA256SUMSと照合する。

## 確認する操作

| 項目 | 確認すること | 結果 |
| --- | --- | --- |
| 導入 | 日本語セットアップが表示され、通常ユーザーの領域に導入できる | 旧候補はHP本体で所有者確認。Sandboxで通常導入画面も確認 |
| 初回起動 | WebView2の有無による挙動、空画面、エラー表示を確認する | 旧候補はHP本体で所有者確認。Sandboxの通常起動失敗は別記録 |
| 権利表示 | インストール先のLICENSE.txt、THIRD_PARTY_NOTICES.txt/jsonが候補の原本と一致する | 再梱包後に確認 |
| ファイルを開く | 日本語・空白・#を含む名前のUTF-8文書を選択・ドロップで開く | 未実施 |
| OSの入口 | 「プログラムから開く」を確認する。既定アプリの変更は本人が選ぶ | 未実施 |
| 移動 | 重複見出し、番号付き見出し、#を含むファイル名へのリンク、戻る・進むを確認する | 未実施 |
| 検索 | Ctrl+F、日本語IMEの変換中・確定後、タブ横断検索を確認する | 未実施 |
| 保存追従 | 他のエディタの上書き・置換保存後に本文が更新され、位置を維持する | 未実施 |
| 外部リンク | 確認前・キャンセル時にブラウザを開かず、明示的な確定後だけ開く | 未実施 |
| 再開 | 複数タブで位置を変えて終了し、再起動後に選択タブ・位置が復元する | 未実施 |
| 表示・操作 | 使用する表示倍率、キーボードのフォーカス、Narratorで主要操作を確認する | 未実施 |
| 更新・終了 | 同じ候補の再導入、終了、アンインストール時の挙動を確認する。データ削除の選択は本人が行う | 未実施 |

## 記録する情報

対象コミット、インストーラー名・ハッシュ、OS・WebView2・表示倍率、実施操作、結果を残す。
失敗時は再現手順とエラーを記録する。私的な文書や認証情報を証拠へ含めない。
CIの成功と、実機での確認結果は分けて記録する。

## 確認済み範囲

CIの整形・Rust・UI回帰・releaseビルド、Sandboxでの表示・検索・目次・戻る、所有者によるHP本体での導入・起動は確認した。
Sandboxの操作結果を本体の全受入確認へ流用しない。詳細は[Windowsの検証記録](VALIDATION_WINDOWS_0_1_0.md)を参照。
デュアルブートの起動順、SSH・RDP等の構築はアプリの導入要件ではなく、この受入手順の対象外とする。
