# Windows配布候補の実機確認

この手順は所有者による内部検証用。インストーラーは未署名で、第三者権利表示の確認も未完了のため、一般配布用とは扱わない。
GitHub Releaseやタグは作成しない。夜間にモニターを接続できてから実施する。

## 開始前

1. Windowsの画面を確認し、初回設定中なら必要な設定を本人が選び、デスクトップまで進める。
2. Windowsのエディション・バージョンと表示倍率を記録する。IPアドレスはUbuntuと同じとは限らない。
3. 必要ならMacからの接続方法を検討する。SSHやリモートデスクトップの有効化は、接続範囲・認証方法を決めてから扱う。
4. Package Windows test candidateの対象コミットと、Check md-viewerの成功を確認する。
5. Actionsの成果物を取得・展開し、インストーラーのSHA-256をINSTALLER_SHA256SUMSと照合する。

## 記録する情報

対象コミット、インストーラー名・ハッシュ、OS・WebView2・表示倍率、実施操作、結果を残す。
失敗時は再現手順とエラーを記録する。私的な文書や認証情報を証拠へ含めない。
CIの成功と、実機での確認結果は分けて記録する。

## 起動順

Ubuntuで設定したUEFI BootNextは次回1回だけWindowsを指定し、通常のBootOrderはUbuntuが先頭。
実際にWindowsが起動したこと、およびその次にUbuntuへ戻ることは、画面で確認するまで未検証とする。
