# md-viewer v0.1.1 — Windows未署名試用版（公開前の草案）

Windows 11 x64向けの未署名NSISセットアップEXEと、対応するソースを配布する予定です。
v0.1.0はソース版のみでした。今回はWindowsでの試用導入を目的とし、閲覧機能・固定依存は変更していません。
この文書は公開操作の承認や、成果物の生成・検査完了を示しません。

## 導入前の制約

**このEXEとmd-viewer本体にはWindowsのコード署名がありません。**
SAC・SmartScreen・組織のポリシー等で導入・起動をブロックされる場合があります。拒否された場合は導入を中止してください。
SAC・Defenderの無効化、除外設定、自己署名証明書の信頼登録、ブロックを回避する操作は案内しません。
署名タグやチェックサムの署名は、Windowsアプリのコード署名とは異なります。

必要なWebView2がない場合、セットアップ時の取得にネット接続が必要です。未導入のクリーン環境での導入一式は未検証です。
Store登録と配布署名は保留です。MSIX試作とmacOSアプリはこの試用版に含めません。
