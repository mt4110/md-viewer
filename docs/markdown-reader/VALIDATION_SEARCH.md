# 検索範囲切替の検証記録

実施日：2026年10月29日。対象：reader/のローカル試作。push・公開・外部送付なし。

## ゴールと完了条件

最終ゴールは、Markdownの扱いに慣れていない人が、受け取った文書を開いて読み続けられること。
現在のV2では複数文書の切替と読書再開を扱う。今回の範囲は検索の対象を明示して目的の箇所へ移動できること。
⌘F／Ctrl+Fの入口を維持し、文書内／開いているタブの切替、結果選択、前後移動、異常系を確認する。
Windows実機と第三者利用者の確認は完了条件を満たしたものとして扱わない。D04・V2全体の完了でもない。

## 実装した動作

- 検索欄は既定で隠す。⌘F／Ctrl+Fまたはメニューから開き、Escで閉じて検索語と強調を消す。
- 範囲は「この文書」が既定。「開いているタブ」ではタブ順、各本文内の順で結果を並べる。
- 文書名と抜粋を表示。結果選択、前／次、検索欄のEnter／Shift+Enterで該当タブの一致へ移動する。
- 一覧は選択後に畳む。「検索結果」で再表示でき、本文を覆い続けない。
- 大文字・小文字を区別しない文字列検索。強調やリンクなどインライン要素をまたぐ語句にも一致する。
- 上限は先頭200件。上限を超える一致を見つけた場合は絞り込みを案内する。全件数とは表示しない。
- 復元した未読込タブは、開いた対象の許可表Knownを通したRustコマンドから本文を読む。画像の読込・復号は行わない。
- 読めない文書の件数を表示し、他の結果を継続して使える。閉じたタブや古い検索要求の結果は破棄する。
- 検索語・結果・検索用本文は永続化しない。未読込タブの本文キャッシュはメモリ内8MiBまで。
- 検索範囲・文言はJA／EN対応。ファイルやフォルダーの再帰検索は行わない。

## 再実行

リポジトリルートで実行する。

```sh
rustup run 1.95.0 cargo test --manifest-path reader/Cargo.toml --locked
rustup run 1.95.0 cargo fmt --manifest-path reader/Cargo.toml --check
rustup run 1.95.0 cargo clippy --manifest-path reader/Cargo.toml --locked --all-targets -- -D warnings
npx --yes markdownlint-cli2@0.24.0 --config .markdownlint-cli2.jsonc
```

UIテストはPlaywrightが利用できるNode環境で実行する。アプリの配布依存ではない。
既定Chromiumが見つからない場合、PLAYWRIGHT_CHROMIUM_EXECUTABLEで既存実行ファイルを指定できる。
別配置のPlaywrightにはNODE_PATHを指定する。テスト用の合成原稿はOSの一時フォルダーに作成して保全する。

```sh
node reader/tests/search-ui.cjs
```

テストはRustの実レンダラーを使う一方、ファイル選択・復元などのIPCを差し替えている。
ネイティブアプリの操作確認とは区別する。Browserプラグインが利用できなかったためPlaywrightを使用した。

macOSでのローカル検証アプリ作成は次のコマンド。出力先は存在しない新しいパスを使う。

```sh
python3 tools/build_dev_app.py --out /tmp/md-viewer-search-review.app
```

今回の最終アプリは `/tmp/md-viewer-search-verified-20261029.app`。
Developer ID署名・公証済みの配布物ではない。以前のアプリ・配布物は上書きしていない。

## 残る制約・未検証

- Windowsの.exeビルド、WebView2、Ctrl+Fの実機操作、IME、表示倍率、Narrator、インストールは未検証。
- macOSのVoiceOverと日本語IMEによる実入力、性能・消費電力、最大20タブでの負荷測定は未実施。
- 検索は本文の表示用内容を対象にする。段落の境界をまたぐ語句、画像の代替文・画像エラー、生成した「文書の情報」の見出し、正規表現検索は対象外。
- 背景の既読込タブは表示用スナップショット、未読込タブは検索時の内容をキャッシュする。背景保存の全件監視はしない。タブ選択時の更新検知で本文変更を反映し、結果も再検索する。
- 検索結果を選んだ時点で本文が違う場合は、その古い位置へ移動せず再検索する。
- キャッシュ8MiBは文字列データの見積り上限で、WebView全体のメモリ上限ではない。画像や大規模タブの低負荷を保証する測定はしていない。
- F3／Cmd+Gの追加ショートカット、戻る／進む、外部Webリンク、参照フォルダー選択は今回の範囲外。
- 第三者利用者の確認は未実施。旧ラボの第三者確認も未実施のまま。
